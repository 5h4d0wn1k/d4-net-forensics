# D4 — Network Forensics Suite

PCAP parsing, flow reconstruction, protocol analysis, IoC extraction.

## Overview

This project implements a network forensics analysis suite that:
- Parses PCAP files using a **stdlib-only** struct-based reader (no scapy required)
- Reconstructs network flows from packet captures
- Analyzes protocols (TCP, UDP, DNS, HTTP, ARP)
- Extracts Indicators of Compromise (IoCs)
- Detects port scanning and data exfiltration
- Identifies suspicious DNS queries and payloads

## Features

- **Own PCAP reader**: struct-based parsing of the pcap global header and per-packet records
- **Packet decode**: Ethernet, IPv4, TCP, UDP (and DNS/HTTP payloads)
- **Genuine fixture generator**: builds a real pcap (Ethernet+IPv4+TCP/UDP) with embedded attack patterns
- **Flow reconstruction**: 5-tuple flow grouping and analysis
- **Protocol analysis**: TCP, UDP, DNS, HTTP parsing
- **IoC extraction**: DNS, IP, payload, and behavioral IoCs
- **Port scan detection**: Identify scanning patterns
- **Exfiltration detection**: Large transfer identification

## Usage

```bash
# Full analysis of a capture
python3 cli.py --pcap capture.pcap

# Demo against the bundled fixture (writes reports/d4_report.json)
python3 cli.py --demo

# Generate test PCAP and analyze
python3 net_forensics.py --generate-test test_capture.pcap

# Show flows only
python3 cli.py --pcap capture.pcap --flows

# Show DNS queries only
python3 cli.py --pcap capture.pcap --dns

# Extract IoCs only
python3 cli.py --pcap capture.pcap --iocs

# Export to JSON
python3 cli.py --pcap capture.pcap --output report.json
```

The engine (`firmware/net_forensics.py`) is stdlib-only (`struct`, `json`, `datetime`, etc.).
The committed fixture `tests/fixtures/network_traffic.pcap` (128 packets) is regenerated by
`tests/generate_fixtures.py`.

## Tests

```bash
python3 -m unittest discover -s tests
```

There are 18 passing unit tests covering the pcap reader (magic, link type, packet count),
IP/transport/port extraction, flow reconstruction, DNS/HTTP parsing, IoC extraction, the full
analysis report, the CLI demo (exit 0 + JSON report), and fixture regeneration.

## Live Lab Test Plan

1. Capture live traffic with `tcpdump -i eth0 -w /tmp/live.pcap` (on a test host you control), then run `python3 cli.py --pcap /tmp/live.pcap`.
2. Verify the reported protocol distribution matches what you saw in tcpdump (TCP/UDP/ICMP counts).
3. For a DNS you intentionally resolved in the capture, confirm its name appears in the DNS Queries section.
4. For an HTTP request you made, confirm the method/URI/host appear in the HTTP Requests section.
5. Trigger an IoC (e.g. `nslookup malware-test.example.com`) and confirm it is flagged as a suspicious domain.
6. Confirm multiple packets in one TCP connection collapse into a single reconstructed flow with the expected packet count.
